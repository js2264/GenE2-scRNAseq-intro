Welcome

This book supports a 2h30 live-coding workshop on the analysis of single-cell RNA-seq data with Bioconductor, taught in the Single-Cell Omics and Spatial Transcriptomics teaching unit of the GenE2 Master 2.

Starting from the UMI count matrix of an adult human testis, you will learn to:

  • explain how a droplet-based experiment turns cells into a matrix of UMI counts;
  • store and explore single-cell data in a SingleCellExperiment;
  • run the standard pre-processing workflow: quality control, normalisation, feature selection, dimensionality reduction and batch correction;
  • cluster cells, find the genes that mark each cluster, and name the clusters, by hand and against a public reference;
  • test for differential expression with pseudobulk samples, the unit of replication being the donor, not the cell.

What you need to know

Basic R: vectors, data frames, indexing with [, calling functions and loading packages with library(). No prior experience of Bioconductor is needed: the workshop introduces the containers it uses as it goes.

The workshop environment

Everything the workshop needs comes in a single Docker image, built from this repository by GitHub Actions: R, Bioconductor and every package of the book, plus the count matrix and the reference data, downloaded in advance.

👉 ghcr.io/js2264/gene2scrnaseqintro 🐳

During the session: Orchestra

Each participant gets their own RStudio Server, running from the workshop image on the Orchestra platform: nothing to install.

  1. Open the Orchestra dashboard (the instructor shares the link) and sign in with a Google account: a personal Gmail address or an institutional Google account both work.
  2. Find the workshop in the catalog and choose Launch. Its status goes from Pending to Starting to Ready: the first launch can take a few minutes, as the image is large.
  3. Choose Open: RStudio opens in a new tab, already logged in.
  4. Create a new R script (File > New File > R Script) and save it in the data folder of your home directory: this is where you will type the code of the session.

A copy of the workshop page, workshop/workshop.qmd, is also in your home directory, in case you lose track of the shared screen.

WarningYour session is temporary

Each session has a countdown, shown on its card in the dashboard: use +1h to extend it. When it ends, everything in it is deleted, except the data folder, which comes back in your next session of the workshop. Download anything else you want to keep (Files pane > More > Export) before the end.

After the session: Docker

The same environment runs on any computer with Docker installed. Start an RStudio Server from the image:

bash
docker run \
    --volume <local_folder>:/data \
    -e PASSWORD=gene2 \
    -p 8787:8787 \
    ghcr.io/js2264/gene2scrnaseqintro:devel

then open http://localhost:8787 and log in as rstudio, with the password set above (gene2). <local_folder>, a folder of your computer, appears as data in RStudio’s home directory: save your work there. For an R console only:

bash
docker run -it ghcr.io/js2264/gene2scrnaseqintro:devel R

On your own computer

You need R (>= 4.6.0), a recent Bioconductor and about 8 GB of RAM. The workshop’s R package lists every package used in the book, so installing it with its dependencies installs them all:

install.packages("BiocManager")
BiocManager::install("js2264/GenE2-scRNAseq-intro", dependencies = TRUE)

The count matrix is downloaded from GEO the first time you run the workshop code, and cached for later sessions.

The dataset

The hands-on session analyses the adult human testis atlas of Guo et al. (2018): 6,490 cells from three healthy young donors, captured in two technical replicates each with the 10x Genomics Chromium platform (GSE112013). The dataset of the hands-on session explains why it makes a good teaching dataset.
